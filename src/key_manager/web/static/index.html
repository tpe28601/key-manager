Git 設定（全域）

設定目前使用者的 Git 預設值。各 Repo 可透過「資料夾設定」或自己的 Git 設定覆蓋這些值。

Commit 作者資訊

Git 會把這個名稱和電子郵件寫入新建立的 Commit。

Commit 與 Tag 的 GPG 簽章

先選一把 GPG 金鑰，再開啟自動簽章並套用。這個開關會同時設定 Commit 和 Tag。

資料夾設定（Profiles）

為指定資料夾及其子資料夾內的 Repo 設定 Commit 作者、GPG 簽章或 SSH 金鑰。未指定的值沿用全域設定。

例如把 D:/Work/ClientA 加到公司用的 Profile，底下的 Repo 就能套用公司的名稱、信箱和金鑰。用「檢查生效值」確認 Git 實際讀到的值及來源。

尚未建立資料夾設定。按「新增設定」開始。

備份與還原

建立 Repo 的本機 Git 設定備份，也可查閱既有的全域和資料夾設定備份。每個設定檔保留最近 20 份。

建立 Repo 設定備份

單一模式可選 Repo 或 Repo 裡的資料夾。批次模式會備份選定位置本身的 Repo（若有），以及掃描找到的最多 50 個子 Repo。每份備份包含該 Repo 的本機 Git 設定檔。
